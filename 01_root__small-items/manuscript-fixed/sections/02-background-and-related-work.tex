\section{Background and Related Work}\label{sec:related}
\textbf{Counterfactuals and code reasoning.}
Executable Counterfactuals~\cite{vashishtha2026executable} distinguishes \emph{interventional} questions (apply a change, predict the result) from \emph{counterfactual} ones requiring latent abduction; our queries are interventional in Pearl's~\cite{pearl2009causality} sense, adopting the XAI term ``counterfactual explanation''~\cite{wachter2018counterfactual,miller2019explanation} for the contrast \emph{shown to a reader}. Execution benchmarks (CRUXEval~\cite{gu2024cruxeval}, CodeMind~\cite{liu2024codemind}, SpecEval~\cite{wang2024speceval}) probe model tracing, while Yang et al.~\cite{yang2025reversion} and CodeCrash~\cite{lam2025codecrash} reveal model fragility to textual cues.

\textbf{Explaining programs and differential analysis.} Cito et al.~\cite{cito2022counterfactual} explain ML models over code;
WatChat~\cite{chandra2024watchat} debugs users' mental models and Whyline~\cite{ko2008whyline} traces questions. Differential symbolic execution~\cite{person2008dse} derives exact path conditions. Quantitative patch impact analysis~\cite{sarker2026impact} computes range-based equivalence lower bounds over modeled numerical domains. Whereas symbolic engines face path explosion on dynamic types, \CoDE handles arbitrary Python data structures by checking LLM-generated predicates on tests. Automated differential testing tools (Mokav~\cite{etemadi2024mokav}, DIFUZZI~\cite{sun2024difuzzi}, DiffTestGen~\cite{hu2026difftestgen}) search for difference-exposing inputs. Unlike test generators that stop at divergence, \CoDE pairs witnesses with test-checked predicates to articulate behavioral boundaries for maintainers.

\textbf{PR testing, impact analysis, and reliability.} Change impact analysis (Chianti~\cite{ren2004chianti}, Caprese~\cite{fard2023caprese}, Athena~\cite{tufano2023athena}) traces affected dependencies. DeepDiff~\cite{sarker2026deepdiff} evaluates patch regression freedom, while ORION~\cite{fu2026orion} synthesizes structured PR oracles for CI gating. \CoDE complements these gating tools by generating human-facing, test-checked review artifacts. Because developers are frequently overconfident on unverified assertions~\cite{kaufman2026judges,rong2026behavioral}, certifying both witness and predicate execution provides an essential trust anchor. Mutation analysis~\cite{jia2011mutation,just2014mutants} provides realistic fault proxies.
